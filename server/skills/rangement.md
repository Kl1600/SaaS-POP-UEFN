# Ranger le niveau

1. Un dossier par type ou par zone : `Appareils/Bouton`, `Zones/Base_Rouge`, `Decor`.
2. Des noms qui disent le rôle : `Minuteur_Manche`, `Spawn_Bleu_2`, pas `Button2`.
3. Pour beaucoup d'acteurs, proposez plutôt « Ranger le niveau » à l'humain (Organiseur de POP) : une seule action, annulable d'un coup.
4. Ne renommez pas un acteur utilisé par un réglage `@editable` sans vérifier ensuite avec `check_level`.
5. Les acteurs verrouillés dans Lore par un autre membre restent tels quels.
